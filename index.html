The first build

The first part of Kadre OS, built around the work that matters first.

This first build gives Kadre two useful systems without pretending we need to redesign every part of the firm at once. It is a place to start, and a real system to build on.

Worker 1 · Lead Desk
A small custom enrichment machine for Kadre’s actual questions.
Input
You choose the organizations and the target types worth pursuing.
Build
We define the five to ten fields and checks that matter to Kadre, then build the workflow around them.
Output
The system returns the organization context, the person who matters, the verified contact, the reason to reach out, the source, and the confidence of the record.
Into your stack
If Factor’s private API exposes what we need, we sync there. If not, we use a dashboard or import/export path.
Outcome: Kadre owns the targeting and the relationships. The repeated work of turning a target into a useful record has somewhere to run.
Worker 2 · Proposal Drafter
A proposal package built from Kadre’s own work.
Input
A real opportunity, the context around it, Kadre’s template, and the past work that should inform the response.
Build
We map the template, organize the source library, and build the first version around one live proposal.
Handoff
You receive a section-by-section narrative and image package in the order your template expects.
You finish
You place and polish in InDesign. The design bar and the final call stay with Kadre.
Outcome: the hunting, repeated rewriting, and image-swapping stop eating the week. The work that makes Kadre’s proposals feel like Kadre’s stays with you.
The first pilot is where we test the real result. The current target is to move toward a 20–40 minute place-and-polish after the package is ready, not to pretend that result is proven before the build.
What this is not. We are not taking over Kadre’s business development, choosing the relationships, or replacing the design practice. We are building and maintaining the machinery behind the work in Kadre’s systems, with Kadre’s data.

The first build is designed for roughly three weeks, assuming we have the materials and access we need. The first 90 days after launch are the initial operating cycle: we put the system into real use, see what the work asks from it, and make the handoff trustworthy.

FAQ

The quick answers

Are you taking over our business development?
No. You choose who to pursue and own the relationships and outreach. We build and maintain the system behind that work.
Is this a generic lead scraper?
No. The Lead Desk is built around the five to ten fields, checks, sources, and confidence rules that Kadre actually needs.
Does this replace proposal design?
No. It prepares the content and image package. You finish it in the template you already use, and the design judgment stays with Kadre.
What happens with Factor?
If Nerin gets access to the private API and it exposes what we need, we can sync there. If not, we use the simplest dashboard or import/export path.
How long does the first build take?
The first working version is designed for roughly three weeks, assuming we receive the template, source material, live proposal, target examples, and access details on time.
What happens after the first build?
The first build moves into a 90-day initial operating cycle at $500/month. We use that time to put the systems into real work, handle edge cases, and tune what needs tuning. After that, ongoing care continues month to month if Kadre wants Clearworks to stay close.
Why is the initial operating cycle required?
Things change fast right now. A live system meets real inputs, real platform behavior, and real use that no demo can fully predict. The initial operating cycle gives us enough time to make the handoff real and see what the work asks from the system.
How does Kadre OS grow?
The Kadre Pursuit System is the first part of the larger Kadre OS. As the business changes, Kadre can choose the next operating problem worth solving. Each new piece is a scoped engagement with its own result, timeline, and price, built to fit the same system.
